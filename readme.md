# SIAKAD SD Rawa Gempol

Sistem Informasi Akademik berbasis Frontend untuk SDN Rawa Gempol.

## Fitur Utama

- Dashboard Admin & Wali Kelas
- Manajemen Data Guru
- Manajemen Data Kelas
- Manajemen Data Siswa
- CRUD Nilai
- CRUD Kehadiran
- Export Laporan Excel
- Role Based Access (Admin & Wali Kelas)
- Sidebar Responsive Modern
- Dashboard Modern UI
- LocalStorage Based System

---

## Teknologi

- HTML
- CSS
- JavaScript
- LocalStorage
- ExcelJS
- Vercel Deployment
